# Fresh novice lesson example

Copy this complete folder into C:\LearningPortal\web\resources\Activities\lesson-starter. The initial lesson and button work without additional downloads. All code is newly authored for this manual; no prior portal code is reused.

Follow Guide 02 in order. The media folder is initially empty except its note. Supply your own permitted media only for those optional exercises. build_media_list.py generates a separate media-list.json; it does not rebuild the main portal catalogue. Rebuild_Catalog.bat rebuilds that catalogue.
