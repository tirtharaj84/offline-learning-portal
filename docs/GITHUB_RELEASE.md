# Offline Learning Portal v1.0.0

A Windows school LAN portal with an offline resource catalogue, configurable NGINX/NSSM setup and uninstall options. This release replaces demonstration worksheets with three illustrated guides covering setup/access, adding multimedia and local HTML resources, and optional Kiwix/ZIM hosting on a separate port and service. Editable guide sources are included.

The runtime baseline was tested by the project owner; detailed evidence and limits are included in docs/VALIDATION.md and docs/TEST_HISTORY.md. Portable catalogue tests and PDF layout checks passed during preparation. Optional Kiwix and reverse-proxy instructions require separate local validation.

Download Offline_Learning_Portal_v1.0.0.zip, extract it, read README.md and review portal-settings.json before installation. Python is needed to rebuild the catalogue, not to browse the supplied portal. Original project files and guides are MIT licensed; retain bundled third-party notices.
