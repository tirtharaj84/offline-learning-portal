# Fresh novice example

The three manuals are 4/10/10 pages. Guide 02 uses newly authored lesson-starter HTML, CSS, JavaScript and optional Python; no code from the author's original portal is used. The core lesson requires no external media. Added media is teacher supplied. Guide 03 uses an independent C:\KiwixPortal deployment with a server subfolder and consistently named starter.zim/second.zim copies. The setup/uninstall runtime is unchanged.
